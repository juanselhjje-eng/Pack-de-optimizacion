# Sistema de recomendaciones

El módulo de recomendaciones analiza únicamente datos recogidos por el diagnóstico básico:

- CPU: uso observado durante una muestra corta.
- RAM: porcentaje de memoria utilizada.
- Almacenamiento: porcentaje libre por volumen.

Los umbrales son orientativos, no diagnósticos definitivos. Un pico de CPU puede ser normal durante una compilación o actualización. La memoria usada por Windows como caché no siempre representa un problema. El espacio libre recomendado depende del tamaño del disco y del tipo de trabajo.

El programa recomienda investigar antes de cerrar procesos o borrar archivos. No aplica cambios automáticamente.
