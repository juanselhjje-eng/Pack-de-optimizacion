# Política de uso de recursos

El optimizador busca evitar restricciones innecesarias, no mantener todos los componentes al 100%.

- CPU y GPU pueden alcanzar cargas altas durante compilaciones, renderizado o juegos si la temperatura se mantiene dentro de los límites del fabricante.
- La RAM debe conservar margen para Windows y otras aplicaciones. Llenarla no mejora el rendimiento.
- Un cuello de botella térmico, energético, de memoria o almacenamiento puede limitar el rendimiento.
- El máximo rendimiento puede elevar calor, ruido y consumo. No debe activarse automáticamente.
- No se desactivan protecciones térmicas, ventiladores automáticos, Defender, firewall ni Windows Update.
- Los cambios futuros deben mostrar efecto esperado, riesgos, respaldo y reversión, y pedir confirmación.

En un portátil ASUS TUF, los perfiles oficiales de energía y ventilación de ASUS son preferibles a forzar frecuencias o voltajes con herramientas genéricas.
