# Funciones incluidas y límites

## Disponibles en el prototipo
- Interfaz Tkinter.
- Inventario del sistema operativo y hardware.
- Uso de CPU, memoria y particiones.
- Prueba ICMP configurable.
- Vista previa de temporales sin borrado.
- Exportación de informe JSON.
- Consulta de herramientas comunes de desarrollo.
- Listado de procesos por memoria.
- Scripts PowerShell de inventario, red, inicio, energía y almacenamiento.

## Pendiente
- Lectura de sensores con una fuente fiable.
- Inventario de controladores firmado y actualizaciones.
- Comparación de rendimiento repetible.
- Interfaz de perfiles con controles reales.
- Gestión de inicio con respaldo y reversión.
- Ajustes de energía validados por modelo de portátil.
- Integración con datos de NVIDIA cuando el controlador lo permita.

Los scripts PowerShell son consultas de solo lectura, salvo la generación de un informe de batería en una ubicación temporal.
