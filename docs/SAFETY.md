# Política de seguridad

1. Diagnosticar antes de cambiar.
2. Mostrar exactamente qué se va a modificar.
3. Solicitar confirmación explícita.
4. Crear respaldo o punto de restauración cuando el tipo de cambio lo permita.
5. Registrar fecha, estado anterior y estado nuevo.
6. Ofrecer reversión y verificar que funciona.
7. No desactivar Microsoft Defender, firewall, Windows Update ni servicios críticos.
8. No terminar procesos del usuario automáticamente.
9. No borrar carpetas completas de caché de herramientas de desarrollo.
10. No aplicar ajustes de red universales: pueden empeorar la latencia o estabilidad.
11. No forzar overclock, undervolt ni límites térmicos.
12. Si no se puede verificar un cambio, no aplicarlo.
